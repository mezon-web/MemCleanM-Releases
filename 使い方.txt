MemCleanM v0.2.0
メモリ管理 / アプリ・プロセスモニター

Windows x64 向けの手動メモリ整理アプリです。
Windows 11で検証。Windows 10は実機未検証です。
ZIPを展開してMemCleanM.exeを起動してください。
.NETランタイムを同梱し、管理者権限やインストールは不要です。

【基本の使い方】
1. 上部の利用可能メモリを確認。余裕がある場合は整理不要です。
2. しばらく使わないアプリを選択。よく使う組み合わせは用途別プリセットへ登録できます。
3. 下部の選択件数を確認して「選択プロセスを整理」を押します。
4. 一覧の下に結果を表示します。結果欄を押すとプロセス別の詳細を展開します。
5. 30秒後にもう一度計測。同じ履歴に記録します。過去の結果は「実行履歴」で確認できます。

【アプリ一覧・選択】
同じEXEのフルパスごとに集約します。別の場所にある同名EXEは別のアプリです。
▸で展開するとPID別の行を表示。アプリ行のチェックは表示条件に合う選択可能な
プロセスだけを選択します。一部選択は横線で表示します。
検索はアプリ名・EXE名・パス・PIDに対応します。
整理可能 / 低負荷候補 / 選択中 / 保護中 / すべて、で絞り込めます。
検索・絞り込み・折りたたみを変えても選択は残ります。
「選択5件 / 検索外2件」のように表示し、件数を押すと選択した全対象を確認できます。
検索外の選択も整理対象になります。「選択解除」で全選択を解除できます。
終了したプロセス・保護対象になったプロセスの選択は解除します。
選択後に新しく起動したプロセスは自動選択しません。

低負荷候補は15秒以上CPUが低負荷、かつRAM常駐量64 MiB以上が目安です。
起動直後は約18秒の計測が必要です。「低負荷候補を追加」は既存の選択を残します。
CPUが低負荷でもGPU処理や通信などで使用中の場合があります。
不要なメモリかどうかを自動判定する機能ではありません。

【用途別プリセット】
「プリセット」タブで、ゲーム前・画像生成前などの名前を入力して「新規」。
その時に選択していたEXEを候補として登録します。
一覧上部の「選択を追加」や「候補EXEを追加」でも追加できます。
未起動の候補も保存し、候補の行の「削除」で登録から外せます。
複製・名前変更・削除にも対応しています。
用途を切り替えると、その用途の保護を適用し、現在起動中の登録候補を選び直します。
「再適用」で後から起動した候補を取り込めます。
起動時は前回の用途の保護だけを復元し、選択は空にします。自動整理はしません。

【保護設定】
行の「設定」または右クリックで「常に保護」「この用途で保護」を選べます。
「保護設定」タブでは共通保護と用途別保護を切り替えて管理します。
アプリ名・パス・起動状態を表示し、「EXEを追加」で未起動のアプリも登録できます。
共通保護と用途別保護はどちらも整理候補より優先します。
用途の登録を削除しても共通保護は残ります。
別EXEの補助プロセスは、必要に応じて個別に候補・保護へ登録してください。

Windowsの処理、重要なプロセス、別ユーザー・別セッション、MemCleanM自身、
作業中または直前に使用していたアプリも保護します。
整理直前にプロセスの同一性と保護を再確認し、CPUが1コア換算で10%超ならスキップします。

【結果・30秒後の計測】
Windows API EmptyWorkingSetで選択プロセスのRAM常駐量を縮小します。
アプリ終了やデータの破棄は行いません。再使用時の読み戻しで遅くなる場合があります。
常駐量合計には共有ページが含まれ、減少量がそのまま空き容量の増加になるわけではありません。
PC全体の利用可能メモリの前後差には、他のアプリの動作も含まれます。
30秒後は同じプロセスか確認して再計測。終了・再起動・取得不可は欠測として扱います。
次の整理・最小化・終了で追跡計測を中止し、その理由を記録します。
30秒待たずに操作・終了できます。
メモリリーク・コミット上限・GPUのVRAM不足は解消しません。

【表示・キーボード】
Ctrl+F：検索 / Space：選択 / 左右キー：アプリの開閉 / ダブルクリック：詳細。
列見出しで並び替え。列のドラッグで順序を変更できます。
「表示」で列を切り替え、表示の初期化もできます。
列幅・順序・表示・並び順、ウィンドウ位置とサイズを終了時に保存します。
RAM常駐：現在物理メモリ上にあるページ。Private Bytes：私有コミット量。
CPUは全論理コア換算です。

【動作・保存先】
手動実行のみ。自動起動・トレイ常駐・ネットワーク通信は行いません。
最小化中は監視を停止します。整理中に閉じた場合は中止要求後に結果を保存して終了します。
%LOCALAPPDATA%\MemCleanM\ 以下に保存します。
settings.json：共通保護（旧版と互換）
profiles.json：用途別プリセット・現在の用途
ui-state.json：表示設定
history\：整理履歴と追跡計測、最大100件
保護・プリセット設定が壊れている場合は、整理を停止して元ファイルを残します。
修復はアプリ終了後に行ってください。表示設定の破損時は初期表示へ戻します。
