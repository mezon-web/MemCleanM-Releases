# MemCleanM v0.3.2（プレビュー）

MemCleanM自身のメモリ使用量と一覧更新の負荷を抑えました。使い方・設定・履歴はそのまま引き継げます。

- プロセス一覧の取得に必要な情報だけを読み取り、作業用の配列と辞書を再利用します。
- EXEパス取得用の大きな一時バッファを削減し、長いパスだけ必要に応じて拡張します。
- アプリごとの合計・表示文字列を再利用し、変化した項目だけ画面を更新します。検索・並べ替え・グラフ描画の無駄な確保も削減しました。
- 保護の更新とCPU計測を分離し、メモリだけ更新する際の重複計算を減らしました。操作中アプリの変化は引き続き即時に反映します。
- 整理直前の同一性・保護条件の再確認を維持しています。新しい自動整理動作は追加していません。

## 計測結果

同じPCの分離デスクトップで、整理なし・新規設定・自動実行OFFとして比較しました。UI計測ハーネスでは60秒間のマネージド確保量が旧版の33.4〜34.3 MiBから10.6 MiBへ、約68〜69%減りました。これは区間内に新しく確保した総量で、RAM常駐量とは別の指標です。

配布EXE同士の60秒比較では、Private Bytesの区間平均が150.2→125.1 MiB（約17%減）、RAM常駐量の区間平均が193.0→182.7 MiB（約5%減）でした。CPUは1コア換算6.18→4.64%。起動と通常終了、ZIP内の全ファイルの一致も確認しています。

起動中アプリやOSの状態で値は変わります。短時間の比較で、削減量を保証するものではありません。強制GCや自身のメモリ整理による見かけ上の削減は使っていません。

## 入手と起動

`MemCleanM-v0.3.2-win-x64.zip`を展開し、`MemCleanM.exe`を起動してください。.NET同梱、管理者権限不要。操作は同梱`使い方.html`で確認できます。

Core 95項目・分離デスクトップUI 109項目を検証。Windows 11 x64で確認し、Windows 10実機は未検証です。標準・最小サイズの一覧17行・9行を維持。125/150%は描画倍率相当の確認です。
