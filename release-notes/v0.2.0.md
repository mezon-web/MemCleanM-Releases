# MemCleanM v0.2.0

一覧・保護・整理の操作をまとめて改善したプレビュー版です。

- アプリを同じEXEのフルパスごとに集約し、展開するとPID別に確認できます。
- 一部選択と検索外の選択保持に対応し、対象を見失いにくくしました。
- 用途別プリセットの作成・複製・名前変更・削除、共通／用途別の保護設定を追加しました。
- 整理後も一覧に留まり、下部で結果と詳細を確認できます。
- 30秒後に同一プロセスを再計測し、同じ履歴へ保存します。次の整理・最小化・終了では中止理由を記録します。
- 列の表示・幅・順序・並び順、ウィンドウ位置とサイズを保存します。
- 黒鉛色とアンバーのコンパクトなUI、25pxの一覧行を維持しています。

Windows 11 x64で、Core 45項目・分離デスクトップ上のUI 44項目が成功しました。配布EXEの起動・正常終了とZIP内EXEの一致も確認済みです。125%／150%相当の描画検査は実モニターのDPI変更による検査とは異なります。

## ダウンロードと起動

Assetsの`MemCleanM-v0.2.0-win-x64.zip`を展開して`MemCleanM.exe`を起動してください。.NETランタイムを同梱しています。`使い方.txt`も同梱します。

ZIPのSHA-256:

```text
bf78027aaa8b3c187d50c1ea066a93b1d90cf915601f0010185aa342518d3249
```

併せて配布するSHA-256確認用ファイルとも照合できます。GitHubの「Source code」リンクは案内リポジトリのスナップショットです。アプリは名前付きのZIPから入手してください。

整理は手動で選んだ対象のRAM常駐量を縮小する操作です。アプリ終了やデータの破棄は行いませんが、再使用時の読み戻しで遅くなる場合があります。詳しくはREADMEと使い方をご覧ください。
