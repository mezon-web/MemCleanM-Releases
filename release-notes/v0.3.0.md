# MemCleanM v0.3.0（プレビュー）

対象を選ぶ操作を「自動選択」で補助します。基本は候補を確認してから手動で整理。必要な場合だけ、メモリ不足時の自動実行をONにできます。

- 自動選択：起動中の全体から候補を追加し、検索を解除して選択中を表示。既存の選択を保持します。
- CPU・I/O・GPU・音声・最近2分の使用を考慮。各プロセスの常駐量128 MiB以上、30秒以上の低負荷を確認します。取得不可は候補から除外します。
- 自動実行：起動時OFF。初期条件は利用可能が10%以下かつ4 GiB以下で30秒継続。60秒以上安定した候補から最大5プロセスを整理します。
- 5分以上の実行間隔、整理したEXEの15分待機、常駐量がすぐ戻る場合の30分待機を追加。
- 手動の選択中・整理中・追跡中は自動実行を待機。ON中は最小化しても動き、OFFで残りを中止。閉じると終了します。
- 履歴に手動／自動の区分と理由を保存。旧設定・旧履歴は継続して使用できます。
- 画面付きHTMLマニュアルを更新し、ZIPに同梱しました。

共通保護・用途別保護・Windowsなどの固定保護は候補より優先します。自動機能も起動中全体が対象で、プリセット候補への登録だけでは範囲を制限しません。

## 入手と起動

`MemCleanM-v0.3.0-win-x64.zip`を展開し、`MemCleanM.exe`を起動してください。Windows 11 x64で確認。.NET同梱、管理者権限不要。操作は同梱`使い方.html`で確認できます。

この操作はRAM常駐量の調整です。アプリの終了やデータ破棄は行いませんが、再使用時に読み戻しが生じる場合があります。常駐量減少はPC全体の空き容量増加を保証しません。
