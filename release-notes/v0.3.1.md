# MemCleanM v0.3.1（プレビュー）

タイトルバーを既存のMemCleanMヘッダーへ統合しました。上端を28px相当の1行にまとめ、一覧を広く表示します。

- 右上に最小化・最大化／元に戻す・閉じるを配置。ヘッダーのドラッグで移動、ダブルクリックで最大化／復元できます。
- 四辺・四隅のサイズ変更、ヘッダー右クリック・Alt+Spaceの操作メニュー、Alt+F4を維持。Windows 11のスナップ用入力判定に対応しました。
- 最大化時の画面外の枠を補正し、ヘッダーと操作ボタンを作業領域内に表示します。
- 同じ画面サイズの検証で、一覧は標準サイズが15→17行、最小サイズが8→9行になりました。
- 整理中に閉じると、中止要求と結果保存を経て終了します。最小化中の監視は自動実行ON／OFFに従います。
- 設定・履歴はそのまま利用できます。HTMLマニュアルの画面例7枚と操作説明を更新しました。

## 入手と起動

`MemCleanM-v0.3.1-win-x64.zip`を展開し、`MemCleanM.exe`を起動してください。.NET同梱、管理者権限不要。操作は同梱`使い方.html`で確認できます。

Core 89項目・分離デスクトップUI 96項目を検証。Windows 11 x64で確認し、Windows 10実機は未検証です。125/150%は描画倍率相当の確認で、実DPI切替とは異なります。スナップ候補ポップアップ自体は分離検査では未確認です。最小幅900px相当が収まる配置を使用してください。
